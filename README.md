인터넷이란?
웹을 포함한 네트워크 전부를 통칭하며, TCP/IP를 기반으로 하고 있다.

브라우저란?
인터넷의 모든 정보에 접근할 수 있게 해주는 프로그램.

HTTP?
하이퍼텍스트를 교환하기 위해 만들어진 규약

URL?
웹에서 자료의 위치, 즉 주소를 나타내는 것.

Server
클라이언트와 네트워크를 거쳐서 서비스하는 컴퓨터.

Client
서버로부터 정보와 서비스를 제공받는 쪽.

API
프로그래밍에서 다른 규격을 가진 소프트웨어끼리 데이터를 주고 받을 수 있게하는 규칙.

Database
데이터 보관소. 다른 사람들과 공유하는 목적.
